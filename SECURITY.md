# Security Policy

## Supported versions

Only the latest release of Darkstar receives security fixes. Please update to the latest release before reporting, and confirm the problem still occurs there.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or Discord.

Use GitHub private vulnerability reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. This creates a private conversation with the maintainers.

Include, as far as you can:

- the affected version and install type (Home Assistant add-on or Docker),
- a description of the issue and its impact,
- steps to reproduce.

Do not include real access tokens, passwords or other secrets in your report. The diagnostics bundle from the Debug page is redacted, but check it before attaching.

## What to expect

The maintainers will acknowledge the report, investigate and keep you informed in the private conversation. Fixes are released in a new version, and the reporter is credited if they wish.
